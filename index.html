Questions, answered

Written so search and AI assistants can quote it verbatim.

How do I embed it in an iframe?

Point the iframe at the preview page with ?embed=1. The header, hero and footer are removed. Pass ?src=<url> to auto-load a document — it opens in a full-screen preview that fills the frame.

Which formats are supported?

PDF, Word (DOCX), PowerPoint (PPTX) and Excel (XLSX / XLS), all rendered on the client.

Do I need a backend or conversion service?

No. Rendering happens entirely in the browser, so files never leave the user's device — no server required.

How do I install it?

Install from npm with pnpm add @ranui/preview, import it once, then use the <r-preview src="…"> element anywhere.
